📐 Calculadora de Raíces

Métodos numéricos: Bairstow (polinomios) y Ridders (f(x) general)

Datos de entrada

Ejemplo: x⁵ - 3.5x⁴ + 2.75x³ + 2.125x² - 3.875x + 1.25 → 1, -3.5, 2.75, 2.125, -3.875, 1.25
Acepta complejas como 1+1i. Si se omiten, no se calculan Er ni εt.

Fórmulas utilizadas

Factor cuadrático: x² - r·x - s

División sintética: bᵢ = aᵢ + r·bᵢ₋₁ + s·bᵢ₋₂  |  cᵢ = bᵢ + r·cᵢ₋₁ + s·cᵢ₋₂

Sistema 2×2 para los incrementos (con cₙ = cₙ₊₁ = 0):

c(n-2)·Δr + c(n-3)·Δs = -b(n-1)
c(n-1)·Δr + c(n-2)·Δs = -b(n)

Raíces del factor: x = (r ± √(r² + 4s)) / 2

Errores: εa = |(xₙ₊₁ - xₙ) / xₙ₊₁| × 100 %  |  Et = x_verdadero - x_aproximado  |  εt = |Et / x_verdadero| × 100 %
